# JavaTeachingSolution

**多模块 Java 教学项目**

</div>

---

## ✨ 简介

用于演示**控制台程序**与 **JavaEE Web 程序**的开发、运行与统一管理。父项目统一管理依赖与运行控制，子项目既可独立运行，也可由父项目通过反射机制启动。

| | 子项目 | 说明 |
| :---: | :--- | :--- |
| 🖥️ | `console_xxx` | 控制台教学示例 |
| 🌐 | `web_xxx` | JavaEE Web 教学示例 |
| 🧰 | `core` | 注解与反射工具 |
| 🎛️ | `core_web` | Web 管理控制台，统一运行与管理所有子项目 |
